# Onboarding de Cliente

## Objetivo

Garantir que, nos **primeiros 7 dias** após a assinatura do contrato, o cliente tenha tudo configurado para o início da operação e sinta que escolheu a agência certa.

## Quando usar

Sempre que um novo cliente fechar contrato — sem exceção.

## Responsável

- **Gestor de conta**: conduz o onboarding.
- **Líder de tráfego**: valida acessos e configurações técnicas.

## Pré-requisitos

- Contrato assinado
- Primeiro pagamento confirmado
- Briefing comercial passado pelo time de vendas

## Passo a passo

### Dia 1 — Boas-vindas

- [ ] Enviar e-mail de boas-vindas com cronograma dos próximos dias
- [ ] Agendar reunião de kickoff (máx. 60 min) para os próximos 2 dias
- [ ] Criar canal/grupo de comunicação com o cliente
- [ ] Criar pasta do cliente no drive compartilhado

### Dia 2 — Kickoff

- [ ] Apresentar equipe responsável
- [ ] Revisar expectativas, metas e KPIs
- [ ] Explicar rituais (reunião semanal, relatórios, SLA)
- [ ] Enviar [briefing detalhado](../modelos/briefing.md) para o cliente preencher

### Dia 3–4 — Acessos e configurações

- [ ] Solicitar acessos: Meta Business Manager, Google Ads, Analytics, site, CRM
- [ ] Configurar/validar pixel do Meta e conversões de API
- [ ] Validar estrutura atual de campanhas (se houver)
- [ ] Auditar criativos existentes

### Dia 5–6 — Estratégia inicial

- [ ] Entregar plano de ação dos primeiros 30 dias
- [ ] Definir estrutura de campanhas seguindo o [guia de estrutura](../conhecimento/estrutura-campanha.md)
- [ ] Aprovar criativos iniciais com o cliente

### Dia 7 — Go-live

- [ ] Subir campanhas seguindo o [SOP de criação](criacao-campanha-meta.md)
- [ ] Enviar comunicado de go-live para o cliente
- [ ] Agendar primeira reunião de [checkpoint](reuniao-checkpoint.md)

## Checklist final

- [ ] Todos os acessos recebidos e testados
- [ ] Pixel e conversões funcionando
- [ ] Campanhas iniciais no ar
- [ ] Cliente sabe como acompanhar resultados
- [ ] Primeira reunião semanal agendada

## Erros comuns

!!! warning "Cuidado com..."
    - **Pedir acesso tarde demais**: solicitar no dia 1, não na véspera do go-live.
    - **Assumir que o cliente sabe de tudo**: explique jargões, nada é óbvio.
    - **Subestimar tempo de aprovação**: criativos podem levar dias para serem aprovados pelo cliente — dê tempo.
    - **Pular o briefing**: sem briefing preenchido, não comece a estratégia.
