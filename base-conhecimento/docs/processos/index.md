# Processos e SOPs

SOPs (*Standard Operating Procedures*) são os procedimentos padronizados que garantem que **toda entrega da agência tenha o mesmo nível de qualidade**, independentemente de quem executa.

## Por que documentar processos?

- **Consistência**: todo cliente recebe o mesmo padrão de atendimento.
- **Escala**: novos membros da equipe começam produtivos em dias, não meses.
- **Qualidade**: erros recorrentes viram checklists e somem.
- **Autonomia**: menos dependência de "só o fulano sabe fazer".

## Como criar um novo SOP

Use este esqueleto para documentar um novo processo:

```markdown
# Nome do Processo

## Objetivo
O que esse processo resolve?

## Quando usar
Em que situação esse SOP se aplica?

## Responsável
Quem executa? Quem aprova?

## Pré-requisitos
O que precisa estar pronto antes de começar?

## Passo a passo
1. ...
2. ...
3. ...

## Checklist final
- [ ] Item 1
- [ ] Item 2

## Erros comuns
Armadilhas conhecidas e como evitar.
```
