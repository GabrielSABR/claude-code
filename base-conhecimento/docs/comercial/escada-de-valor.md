## Como apresentar a escada para o cliente

1. **Começe pelo problema**, não pelo preço
2. **Mostre o sistema completo** (GMB + Tráfego + LP), explicando por que cada peça importa
3. **Ofereça a porta de entrada primeiro** — LP ou GMB — para gerar confiança
4. **Evolua para os recorrentes** conforme o cliente vê resultado
5. **Nunca venda um serviço solto sem explicar onde ele se encaixa na escada**

!!! tip "Regra de ouro"
    Valor baixo vende mais rápido; valor alto retém mais tempo. A escada existe para cobrir os dois momentos.

!!! warning "Condições especiais"
    Qualquer desconto ou condição fora da tabela deve ser **condicionado a fechamento imediato**. Nunca dar desconto "pra pensar" — perde urgência e desvaloriza o serviço.
