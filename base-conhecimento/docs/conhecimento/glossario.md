# Glossário

Termos e siglas usados no dia a dia da agência. Se encontrar algo que não está aqui, **adicione**.

## A

**A/B Test**
: Teste comparativo entre duas variações (ex: dois criativos) para identificar qual performa melhor.

**Advantage+**
: Conjunto de automações do Meta Ads (público amplo, criativos dinâmicos, posicionamentos automáticos).

**Alcance**
: Número de **pessoas únicas** que viram um anúncio.

**ATC (Add to Cart)**
: Evento de adicionar produto ao carrinho. Métrica importante para funil de e-commerce.

## B

**BOFU (Bottom of Funnel)**
: Fundo de funil. Público mais quente, próximo da compra.

**BM (Business Manager)**
: Central de gerenciamento do Meta. Onde ficam contas de anúncio, páginas, pixels e acessos.

## C

**CAC (Custo de Aquisição de Cliente)**
: Quanto custou, em média, para adquirir um novo cliente. Considera todos os custos (mídia, fee, etc.).

**CAPI (Conversions API)**
: API do Meta para enviar eventos de conversão direto do servidor, sem depender só do Pixel.

**CBO (Campaign Budget Optimization)**
: Otimização de orçamento no nível da campanha. O Meta distribui automaticamente entre os conjuntos.

**CPA (Custo por Aquisição)**
: Gasto dividido pelo número de conversões.

**CPC (Custo por Clique)**
: Quanto custa, em média, cada clique no anúncio.

**CPM (Custo por Mil Impressões)**
: Quanto custa atingir 1000 impressões.

**CTR (Click-Through Rate)**
: Cliques ÷ Impressões. Indica o quanto o criativo chama atenção.

**Criativo**
: A peça em si (imagem, vídeo, texto). É o que o usuário vê.

## F

**Frequência**
: Quantas vezes, em média, a mesma pessoa viu o anúncio. Acima de 3/semana começa a saturar.

**Funil**
: Etapas que o cliente percorre: topo (descoberta), meio (consideração), fundo (decisão).

## I

**Impressão**
: Cada vez que o anúncio foi exibido. **Diferente de alcance** (que conta pessoas únicas).

**ICP (Ideal Customer Profile)**
: Perfil do cliente ideal. A base da segmentação.

## L

**LAL (Lookalike)**
: Público semelhante. O Meta cria um público parecido com uma base que você já tem.

**LTV (Lifetime Value)**
: Quanto um cliente gasta ao longo de toda sua relação com a empresa.

## M

**MOFU (Middle of Funnel)**
: Meio de funil. Público já aquecido mas ainda não decidido.

## O

**ODAX**
: Modelo atual de objetivos do Meta Ads (simplificado, baseado no resultado desejado).

## P

**Pixel**
: Código JavaScript que roda no site do cliente e envia eventos para o Meta (PageView, Purchase, etc.).

**Posicionamento**
: Onde o anúncio aparece: Feed, Stories, Reels, Marketplace, etc.

## R

**Remarketing (Retargeting)**
: Impactar quem já interagiu com o negócio (visitou site, engajou, etc.).

**ROAS (Return on Ad Spend)**
: Receita dividida pelo gasto em mídia. Ex: ROAS 5 = R$5 de receita para cada R$1 investido.

## T

**TOFU (Top of Funnel)**
: Topo de funil. Público frio, ainda não conhece a marca.

## U

**UTM**
: Parâmetros adicionados à URL para rastrear origem do tráfego no Google Analytics.

## V

**VTR (View-Through Rate)**
: Taxa de visualização completa de um vídeo.
