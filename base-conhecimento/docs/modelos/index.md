# Templates e Assets

Modelos prontos e reutilizáveis para acelerar o dia a dia. **Não reinvente a roda a cada novo cliente** — use o template, adapte e entregue mais rápido.

## Templates disponíveis

- [Briefing de cliente](briefing.md) — formulário inicial para novos contratos
- [Proposta comercial](proposta.md) — estrutura padrão de proposta

## Como usar

1. Copie o conteúdo do template
2. Cole no seu documento (Google Docs, Notion, etc.)
3. Personalize com os dados do cliente
4. Salve no drive do cliente

## Como criar um novo template

Se você percebeu que está fazendo o mesmo documento do zero toda vez, **crie um template**. Regra simples:

> Fez 3 vezes igual → vira template.

Crie um arquivo novo nesta pasta e adicione a entrada no `mkdocs.yml`.
